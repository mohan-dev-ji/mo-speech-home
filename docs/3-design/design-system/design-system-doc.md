# App design system doc
We need a clear and concise document that reads as a portrait pdf doc. Here we establish the philosophy and components behind the design of the online app. Live components from the figma file can be instanced into the doc frame with a description. This needs to be a well designed and easy to read document that will also showcase the founder's ability to construct well thought out functional design systems.

## The problem
Going into the marketing site design and marketing material graphics we need a document that shows the functional detail of the apps design. The figma file exists but no read through document has been constructed that compiles the whole system. Such a document will be useful for AI design agents to suggest directions to take on the upcoming marketing site and gfx material tickets as well as a portfolio demonstration of professional design system development.

## Proposed solution
Make a design system document that reads as a4 reading material in figma. Use instances of all the components and order them into chronological sections with a sentence to paragraph explanations to accompany.

Maybe think of using the figma components to rendering an html version with the sections in a side menu, which will keep the pages lean and focused.

Maybe this is the main version and the portrait A4 version is the html file as a responsive layout for small screens.

Online clickable html design system site.

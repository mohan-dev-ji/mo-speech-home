# Pro and Max themes
Pro and Max themes are what takes Mo Speech's visual aesthetics beyond any AAC on the market. We are going to tap into the autistic trait of concentrating on infinite loops in order to hold their concentration on their talking device aka Mo Speech. The idea is if there is a animated loop using elements of their special interest as the bg color this will help them bind with there device - personalising it and making it special to them. 

## The problem
The problem is one of the main reason why I decided to build Mo Speech.  All the AACs on the market prove that this is a great technology that help many people but it also looses a lot of people.  The outdated UI is replicated through out AAC companies and does not allow for customisation which could be a big factor in retaining more users.

## Proposed solution
Use figma, paper and even remotion to create animated textured and gradient style background visuals that seamlessly loop.  Try to keep to a them that could represent a real obsession that an autistic person might have such as water, sky, space. Also be experimental and try to create some abstract movements just to see where it takes you.

This linear project should also contain the backend interface in /admin where themes can be created, tested and published. We need to review the admin/themes page where we can edit life cycle, unpublish and remove. We also need to create a way of editing existing themes and creating new ones. One way would be to go a new route on edit or create new theme buttons. Here we would have the whole design system for each theme laid out in an editable format. The main background color is either a flat color or a code box to paste animating react backgrounds. The surface and card tokens have noise, grain, blur and opacity adjustment nobs to add a glass effect over Max tier bg animations. There should also be a preview at the bottom of the page that updates on the fly so we can see without publishing.
